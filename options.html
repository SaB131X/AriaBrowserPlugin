Aria2 RPC Settings

By Default: http://localhost:6800/jsonrpc
Leave empty if None

How to install aria2 (list of Packet Managers commands)

winget install -e --id aria2.aria2
sudo pacman -S aria2
sudo apt update && sudo apt install aria2
sudo dnf install aria2
sudo zypper install aria2
sudo apk add aria2

How to launch aria2 with RPC

aria2c --enable-rpc --rpc-listen-port=6800 --rpc-secret=YourSecretToken -D

Recomended aria2 daemon config

enable-rpc=true
rpc-allow-origin-all=true
rpc-listen-all=false
rpc-listen-port=6800
rpc-secret=YourKey
continue=true
max-concurrent-downloads=3
split=8
max-connection-per-server=8
dir=E:\aria2
input-file=E:\aria2\sesFiles\aria2.session
save-session=E:\aria2\sesFiles\aria2.session
save-session-interval=60

How to launch aria2 with your config

aria2c --conf-path="C:/Users/User1/.aria2/aria2.conf" -D
